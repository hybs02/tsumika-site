Claude CodeでブログとAI自動化を実際に運用している記録

自動更新ブログ構築キット（無料配布）

このサイトは、記事の生成から公開までをスクリプトで回しています。その仕組みは 自動更新ブログを作った全記録 に書きましたが、記事を読んでも結局は自分で書き起こす必要があります。それなら動いているもの自体を配ったほうが早いと思ったので、そのまま置いておきます。

配っているもの

書き起こしの解説ではありません。tsumika.net が実際に使っているスクリプトそのままです。

ファイル役割
pipeline.py題材の取得・記事追加・ビルド・デプロイの入口
site_gen.pyMarkdown → 静的HTMLサイト生成（目次・OGP・構造化データ込み）
publish_one.py予約記事を1本公開。reviewed: true の記事しか通さない機械的ゲート
deploy_site.py生成物を公開用リポジトリへ反映
make_ogp.pyOGP画像の生成
repurpose.py公開記事を X / note 向けの投稿素材に変換
QUALITY_POLICY.md公開前の推敲ルール。AI記事を薄くしないための実際のチェックリスト
CYCLE.md / REFILL_ROUTINE.md1サイクルの作業台本と、題材が尽きたときの補充手順

Python標準ライブラリだけで動くので、pip install は要りません。

一番見てほしいのは QUALITY_POLICY.md

スクリプトより、こちらのほうが大事だと思っています。

AIに記事を書かせる仕組みを作ると、質の低い記事が自動で出続ける装置が完成してしまいます。それを止めているのが、reviewed: true が立っていない記事は公開されないという機械的なゲートと、その前に必ず通す推敲チェックリストです。

仕組みを配るなら、ここも一緒に配らないと意味がないと考えました。

受け取り方

下のフォームからメールを登録してください。登録の確認メールに、キットのダウンロードリンクを入れて送ります。

配信するのは新しい実験の記録だけです。売り込みはしませんし、解除はいつでもできます。

正直に書いておくこと

  • これは魔法ではありません。自動化されるのは「書いた後」の工程で、記事の中身は結局書く必要があります
  • このブログ自体、まだほとんど収益が出ていません。仕組みは動いていますが、仕組みがあれば儲かるわけではない、というのが今のところの結論です
  • 固定費はドメイン代の年1,800円だけです。その内訳は 運営費を全部公開する記事 に書きました

自由に使って、改造して、自分のブログに使ってください。再配布や販売だけは控えてもらえると助かります。

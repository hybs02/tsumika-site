Claude CodeでブログとAI自動化を実際に運用している記録

2026-11-19

ツールサイト公開2週間の結果は表示3・クリック0。先に決めた表で判定する

執筆： hybs02

実体験収益化副業ストック収入

11月15日、公開から2週間たったツールサイトの Search Console を開きました。11月1日から14日までで、検索結果に出た回数は3回、クリックは0回でした。

ツールサイトを作ったその日に公開した話 で、結果は見られていなかった時も書くと約束していました。その答え合わせです。数字を見る前に決めておいた表に、この数字を当てはめます。

2週間の数字

数字を読んだのは、記事の補充を任せている Claude Code の定期実行 です。11月15日に、私のブラウザで Search Console の画面を開いて読ませ、判定の案まで出させました。

項目11月1日〜14日
表示回数3
クリック数0
平均掲載順位29.3
表示されたページ喪中はがきの道具のページだけ
検索語出ない（件数が少なく、Google が伏せる）

平均29.3位は、1ページ10件で数えると3ページ目あたりです。表示が3回しかないので、この順位もほとんど当てになりません。

検索語が見えないのも痛い所です。どの言葉で出たのかが分からないと、題名をどちらに寄せればいいかの手がかりがありません。

索引には入っていた

数字の次に、ページが Google の索引に入っているかを見ました。

ページ状態
喪中はがきの道具登録済み（11月1日に登録をリクエストしたページ）
トップ「URL が Google に認識されていません」
プライバシー同上
ページの一覧（sitemap）11月1日の「取得できませんでした」のまま。その後、取りに来ていない

sitemap が取れていないので、サイトの側が壊れているのかを疑いました。公開している sitemap を開くと、応答は200、種類も XML、中身の URL も正しい。サイトの側には直す所がありませんでした。

道具のページからはトップとプライバシーへリンクを張ってあります。それでも、登録をリクエストした1ページだけが索引に入り、残りは Google がまだ知らない。2週間でこうなりました。リンクをたどってもらえていない理由は分かっていません。

先に決めた表に当てはめる

公開の記事 に書いた表は、次のとおりです。

2週間後の状態次の手
検索の索引にまだ入っていない待つ（Search Console の URL 検査で確かめる）
索引に入っているのに表示されない題名と検索語を変えて、1回だけやり直す
見られているのに使われない捨てる
使われているのにお金にならない紹介の置き方を変えて、1回だけ試す
お金になった力をこれに集める

公開の日に決めた表は、2行目からの4行でした。1行目の「待つ」は、索引に入るまでの扱いが決まっていなかったので、その記事を書く時に足しています。4行目は、稼ぎ方を広告から紹介料に変えたのに合わせた言い方です。

ページごとに当てはめると、こうなります。

ページ当てはまる行次の手
道具のページ2行目（索引に入っていて、表示は2週間で3回）題名と検索語を変えて、1回だけやり直す
トップ・プライバシー1行目（索引にまだ無い）待つ

道具のページは3回だけ表示されています。表の言葉どおりの「表示されない」ではありません。定期実行の案は、これを「ほぼ表示されていない」とみなして2行目にしています。「見られているのに使われない」と言えるほどは、まだ見られていません。

案の作業は3つです。

作業当たる行Search Console での操作
道具のページの題名を、検索の多い「喪中はがき 文例」に寄せる2行目のやり直し（サイトの側で直す）
sitemap をもう一度送る1行目の手入れサイトマップ → 同じ URL を送信
トップのページの登録をリクエストする1行目の手入れURL 検査に URL を入れる → インデックス登録をリクエスト

そのうえで12月1日にもう一度数字を見て、表示が50回に届かなければ捨てて、次の候補に移る、という案です。50回は、2週間で3回だった数字が十数倍にならないと届かない線です。どの期間で数えるかは案に書かれておらず、この案を採るかも、まだ決めていません。

時期の問題

この判定には、決めた時に考えていなかった問題があります。喪中はがきは12月の初めまでに出すものです。12月1日に数字を見る頃には、今年の山がほぼ終わっています。

やり直しの2週間で数字が伸びても、それが題名を変えた効果なのか、山が来た効果なのかは分けられません。逆に伸びなかった時、来年の山まで残すかどうかも、今の表では決まりません。道具は寒中見舞いの文面にも切り替えられるので、1月と2月にもう一度小さな山はあるはずですが、その数字はまだ誰も見ていません。

手を付けていない作業

ここまでの数字と案は、11月15日に揃っています。この記事を書いている11月18日の時点で、3つのやり直しはどれもまだやっていません。Search Console の操作は私のアカウントで行うもので、私の番です。

出品0個だった話 では、作る所が速くなっても、人の手が要る1歩で止まっていました。今回も、数字を読んで案を出すところまでは無人で済んでいて、残っているのは私が押す数回の操作です。

稼ぎは、2週間たっても0円です。紹介料の登録もまだなので、仮に人が来ても、今はお金になる道がありません。12月1日の数字は、良くても悪くても、またここに書きます。

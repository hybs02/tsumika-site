AI自動化で稼ぐラボ

Claude CodeでブログとAI自動化を実際に運用している記録

2026-11-09

デジタル商品の副業、道具を作って5か月で出品0個。原因は出品の手間

執筆： hybs02

実体験副業ストック収入収益化Claude Code

6月2日、デジタル商品を作って売るための道具を Claude Code に作ってもらいました。商品の企画から出品文の下書き、売上の記録までをまとめたもので、90日の計画もつけました。最初の1週間で3個、90日で30個です。

11月1日の時点で、出品した商品は0個、売上は0円です。

作る所は AI でずいぶん速くなりました。手を付けなかったのは、作ったものを売り場に出す所でした。

作った道具

道具はコマンドで動く小さなもので、このPCの中だけで完結します。外のサービスにはつながず、費用もかかりません。

命令やること
ideas放置で売れやすい商品の種類を並べる（プロンプト集・テンプレート・小さな電子書籍など）
new商品を1つ企画し、作業用のフォルダと企画書を作る
listing出品ページに貼る文章の下書きを作る
publish出品したら、その URL を記録する
sale売れたら、金額を記録する
dashboard商品の数・売上・次にやることを出す

一緒に作った計画書には、分担がこう書いてあります。管理は道具、中身を作るのは Claude、私は「出品ボタンを押すだけ」。

いま dashboard を開くと、こう出ます。


商品数         : 0  (出品済 0 / 制作中 0)
累計売上       : 0 円  (0 件)
次の一手:
  ▶ まず資産5個を目標に。点数が増えるほど“どれかが売れる”確率が上がる

道具は5か月、同じことを言い続けています。

90日の計画と、実際

時期計画実際
1週目カテゴリを決めて、最初の3個を出品0個
30日目10個0個
90日目（8月31日）30個。売れないカテゴリは捨てる0個

計画どおりにいかなかった、というより、1個目に手を付けていません。企画の命令（new）も一度も使っていません。

作ったその日に、自動のブログへ乗り換えた

道具を作った6月2日の夜、私は Claude Code に別のことを頼んでいます。「出品作業すら無く、何もしなくても回り続ける仕組み」です。それがこのブログの自動公開の仕組みになりました。

同じ日に出した AIで副業を自動化する現実的な方法 では、デジタル商品を「検討して、今はやっていないもの」に入れ、理由を「売るに値するものが自分の中にまだ無い」と書いています。それも本当です。ただ、その日の頼み方を見返すと、嫌がっていたのは出品の作業そのものでした。道具を作った時点で、出品の手前で止まることはほぼ決まっていたと思います。

もう1つ、出品の手前で止まっているもの

7月の終わりに、もう1つ道具を作っています。マーダーミステリー（集まって遊ぶ推理ゲーム）のシナリオを作って、創作物の通販サイト BOOTH で売るための道具です。

これを選んだのは、7月30日に BOOTH を調べた時の数字でした。マーダーミステリーのカテゴリの出品は1,395件で、単価は500〜3,000円ほど。人気作には、お気に入りが数千から1万を超えて付いていました。出品の数のわりに、関心を集める作品が多い。中身が文章だけなので、1本作れば何本売っても費用は増えません。

1本目は7月末にでき、その後も直し続けて、10月30日に、犯人が1人に決まるか、全員に隠し事があるかといった検査と、経緯を知らない AI に解かせる確認をすべて通りました。半分まで読んだ AI は2体とも犯人を35%、全部読んだ AI は74%と75%の確からしさで当てています。作品名は伏せておきます。

こちらは、出品の作業もほとんど道具に入っています。商品名・タグ・説明文・見本の画像は道具が作り、出品フォームへの入力も Claude Code がブラウザで行って、公開ボタンの手前で止まる作りです。合格判定で残っているのは1件だけで、出品の時に名乗る名前が空になっています。ショップを開いて、その名前を決める。そこは道具ではなく私が決めることで、まだ決めていません。

出品で残る作業

出せていない人向けに、作り終えてから公開までに残る作業を並べておきます。1つ目の道具では、どれにも手を付けていません。2つ目の道具では、下の3つは道具に入っていて、残っているのは1行目の名前だけです。

出品で残る作業中身
売り場を開くショップを作り、そこで名乗る名前を決める
出品ページ題・説明・値段・見本の画像を整える
規約AI で作ったものの扱いを、売り場ごとに確かめる
最後の確認公開ボタンを押す前に、中身を自分で読む

規約は、AI で量産するつもりの人ほど先に読んだほうがいいです。BOOTH は2025年7月に、パターン化した作品の大量出品や、特定の作品・作家に依拠した商品の大量・連続的な出品への対応を強め、商品やショップの非公開、アカウント停止まで行うと発表しています（GameBusiness.jp の記事）。

1つずつは難しくありません。ただ、締め切りも無いし、やらなくても何も壊れません。

このブログの在庫切れと同じ形です。88日止まっていた話 では、公開は自動にしたのに、記事を足す所が人の手のままでした。今回も、作る所は道具にしたのに、出す所は人の手のままでした。

止まっていた分の損は、お金ではありません。道具はどちらもこのPCで動き、使っている Claude の契約はほかの作業でも払っているものです。計画どおりなら8月末には30個並んでいて、何が売れて何が売れないかも分かっていたはずです。今は、何が売れるかが分かりません。

これからは決めていない

続けるか、やめるかは決めていません。2つ目の名前をいつ決めるかも、決めていません。

作る道具は2つあります。1つ目は種類の一覧から先に進んでおらず、2つ目は公開ボタンの手前まで用意ができていて、名前を待っています。

手間を道具に移しても、決めることは残ります。自分の道具でも、「出品済」と「制作中」を並べ、公開までに残っている作業のうち、作業ではなく決めることがどれかを書き出すと、どこで止まっているかが見えます。私の場合、2つ目に残っていたのは決めることが1つだけでした。

ブログで稼ぐほうの数字は 記事ゼロでPVが増えた話 に書きました。こちらも収益は0円です。

この数字の読み方

正直に補足します。上の閲覧数は、人間の読者数ではありません。

閲覧数はサイトの手前（配信サーバー）で数えているため、検索エンジンのクローラーや各種の自動巡回も含まれます。もし人間の読者が増えているなら、記事が増えるにつれて数字も伸びるはずです。実際には月ごとの数字がほぼ横ばいで、これは定期的に巡回する機械的なアクセスが大半を占めていることを意味します。

つまり現状は、人間の読者はほとんど来ていないというのが実態です。公開から間もない個人サイトで、検索エンジンからの評価が育つには数ヶ月かかるとされているので、想定の範囲ではあります。ただ、想定内だからといって放置していい話でもありません。

数字が動いたら、その原因もあわせて書きます。

このほかにかかっているもの

上の表の「固定費」は、サイトを動かすためのインフラ費用だけです。実際にはこれとは別に、記事の作成や仕組みづくりに使っているAIツールの利用料がかかっています。こちらはブログ専用の支出ではなく、ほかの用途と共用しているため、この表には含めていません。

つまり上の損益は「インフラ費用に対する損益」であって、投じたコスト全体に対するものではない、という点はご承知おきください。時間という最大のコストも、金額には表れていません。

正直な現在地

収益はまだ立っていません。広告もアフィリエイトも入れていないので、当然といえば当然です。

今やっているのは、記事を積んで検索から人が来る状態を作る段階です。ここを飛ばして収益化しても、見る人がいなければ意味がないと考えています。その判断の理由は あえて収益化を急がなかった話 に書きました。

この数字が動いたら、良い方向でも悪い方向でも、そのまま更新します。

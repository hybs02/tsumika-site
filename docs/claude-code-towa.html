Claude Codeとは？普通のチャットAIと何が違うのかを実例で説明する

執筆： hybs02

Claude CodeAI自動化実体験ブログ運営

Claude Codeの説明は、たいてい「ターミナルで動くAIコーディングツール」で終わります。間違ってはいないけれど、これだけ読んでも「で、何が嬉しいの？」がピンと来ない。

このブログは、Claude Codeに作らせて、いまも Claude Code で回しています。その立場から、普通のチャットAIと何が違うのかを、実際に頼んだことで説明します。

一言でいうと「作業を実行する人」

普通のチャットAIは、聞けば答えを返します。でも、その答えを実際に自分のパソコンで実行するのは自分です。料理でいえば「レシピを教えてくれる人」。

Claude Codeは、そこが違います。パソコンの上でファイルを読み書きし、コマンドを実行し、調べ物までして、作業を進めます。レシピを読み上げるのではなく、台所に立って料理を作り、皿に盛って出してくる。

何が違うのか、具体的に

同じ「ブログを作りたい」という相談をした場合を比べてみます。

普通のチャットAIは、必要な手順を説明してくれて、コードも書いてくれます。ただ、そのコードをコピーして、正しい場所に貼り付けて、保存して、実行するのは自分です。エラーが出たら、そのエラーをまたコピーして質問する。この往復が続きます。

Claude Codeは、ファイルを作り、コードを書き込み、実行し、エラーが出れば自分で直して、動くところまで持っていきます。こちらは結果を確かめる側に回ります。

確かめないとどうなるかも書いておきます。このサイトでは、記事の表が崩れたまま公開され続けていました。表を使うと私が伝えていなかったからです（正直レビュー に書きました）。

このブログで実際に頼んだことと、その後

このサイトで実際に頼んだことを挙げます。専門用語は使いませんでした。ただ、何を作りたいかは具体的に言う必要がありました。

頼んだことできたものその後
テキストファイルを置いたら記事になる仕組みを作ってサイトを生成するプログラムいまも記事はこれで出ている
日本語が文字化けするから直して原因（Windows の文字コード）を特定して修正詳しくは Windowsの3つの地雷
月曜と木曜の朝7時に自動で公開されるようにして書き溜めた記事を1本ずつ出す仕組み7月に起動ファイルの改行コードで1か月、8月から在庫切れで88日止まった
アクセス数と収益をまとめて見られるようにして数字を集める管理用のパネル7月のPVを月の途中の値で記録していたのを、あとで直した

できたものはどれも動きました。止まったのは、動いた後です。1ヶ月止まっていた話 も 88日止まっていた話 も、作った時には誰も気づいていない所で起きています。

どんなことに向くか

定型作業の自動化

ファイル整理、形式変換、設定の修正。「やれば終わるが面倒」な作業は速くなります。

繰り返し使う仕組みづくり

一度作れば何度も使えるものと相性がいい。このサイトの「記事を在庫に置けば自動で公開される」仕組みがそれです。

定期実行との組み合わせ

決まった時間に決まった処理を回す使い方もできます。ただ、手を離すと、止まっても気づけません。このブログが2回止まったのは、どちらも手を離している間でした。

「ターミナルが怖い」問題

非エンジニアが最初に身構えるのは、たぶん黒い画面（ターミナル）です。私も最初は身構えました。

2026年11月の時点で、Claude Code はターミナルのほかに、デスクトップアプリやブラウザからも使えます。私はいま、デスクトップアプリから使っています。

どの入口でも、やることは「日本語で頼んで、返事を読む」です。チャットアプリと大きく変わりません。違うのは、返事と一緒に実際の作業が進んでいくことです。私の場合、画面に慣れるより、頼み方に慣れるほうに数日かかりました。

料金の考え方

Claude Code は、Claude の無料プランでは使えません。有料の契約が要ります。最新の金額は公式の料金ページで確かめてください。

私の契約は、このブログ以外の作業でも使っているので、運営記録 の費用には入れていません。このブログの収益は、まだ0円です。元が取れたかどうかは、まだ言えません。

向き不向きと、最初の一歩

向いているのは、面倒な作業を繰り返している人と、何かを仕組みにしたい人です。向いていないのは、単発の質問に答えてほしいだけの人（それなら通常のチャットAIで十分）と、出てきたものを確かめずに使いたい人です。

Claude Code は手を動かしてくれますが、何を作るかを決めるのと、出来を確かめるのは人の仕事として残ります。

私は「このフォルダに何があるか教えて」から始めました。慣れてきたら、自分が面倒だと思っている作業を1つ任せてみる。

このブログは、こうして Claude Code に作らせて回しています。作った全工程は 構築の全記録 に、ブログ以外に試した稼ぎ方は AIで副業を自動化する現実的な方法 に書きました。

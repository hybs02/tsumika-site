Claude Codeで非エンジニアが「できたこと・できなかったこと」正直レビュー

執筆： hybs02

Claude Codeレビュー非エンジニア実体験ブログ運営

プログラムを書いたことがないまま、Claude Code でこのブログを作りました。2026年11月の時点で、5か月ほど Claude Code で回しています。

確かに便利です。でも万能ではありません。この記事では、作ってみて分かったことと、しばらく運用して初めて分かったことを分けて書きます。道具そのものの説明は Claude Codeとは？ に譲り、ここでは評価に絞ります。

できたこと

日本語のふわっとした依頼が通る

一番驚いたのはここでした。専門用語で正確に指示しなくても、意図を汲んで動くものが返ってきます。コマンドを暗記する必要も、文法を勉強する必要もありませんでした。

私の場合、ブログの生成から公開までの仕組みを、半日でひと通り動かせました。プログラムを書いた経験がない状態からです。

エラーで止まらない

Claude Code は、エラーが出ると原因を調べて直すところまで自分で進めます。「動かない、なぜか分からない、詰んだ」という状態になりにくい。

それでも、Windows ならではのエラーには何度か当たりました。日本語の文字化けなど、実際に踏んだものと直し方は Windowsで踏んだ3つの地雷 にまとめています。

期待ほどではなかったこと

丸投げでは、ぼんやりしたものが出てくる

何を作りたいかが自分の中で曖昧なまま投げると、出てくるものもぼんやりします。

「いい感じのブログを作って」より「テキストファイルを置いたら記事になる仕組みにして」のほうが、はるかに良いものが返ってきました。完成形を具体的に言えるようになってから、返ってくるものの質が明らかに上がっています。作りたいものを言葉にする役目は、こちらに残ります。

指示していないことは、やらない

これは運用してから痛感しました。

私は記事に表や引用を書いていたのですが、サイトを生成する部分がそれに対応していませんでした。結果、表がそのまま崩れた状態で公開され続けていた。私が「表を使う」と指示していなかったからです。

AI は頼まれたことは的確にやります。でも「言われていないが必要なこと」は補ってくれません。何が抜けているかに気づくのは、結局こちらの仕事でした。

作ったものは、静かに壊れる

自動で記事が公開される仕組みを作り、満足していました。ところが後日確認すると、1ヶ月以上まったく動いていませんでした。原因は、起動ファイルの改行コードという些細な形式の違いと、定期実行の登録そのものが消えていたことの2つです（1ヶ月止まっていた話）。

AI は作るのが速い。だから作って終わりになりやすい。でも動き続けるかどうかは別の問題です。

止まったら警告が出るようにしても、それで足りるわけではありませんでした。8月から10月末まで、このブログは在庫切れで88日止まっています。警告は開いた時にしか見えず、私は開いていませんでした。今は、記事の補充そのものを Claude Code の定期実行に回しています（88日止まっていた話）。気づく仕組みより、私がいなくても回る仕組みのほうが効きました。

中身の良し悪しを決める基準は、人が持つしかない

文章でもコードでも、それっぽいものはすぐ出ます。でも「それっぽい」と「本当に良い」は別物です。後から自分の仕組みを点検したら、動いてはいるが問題のある箇所がいくつも見つかりました。動いていることと、正しいことは違います。

今このブログでは、定期実行で書いた記事を私は読んでいません。代わりに、何を良しとするかを基準に書き出し、機械の検査と、書いた経緯を知らない別の AI の読み手の判定を通ったものだけを出しています。基準を決めるところは自動にしていません。関門が見落としたものは、そのまま出ます。

誰に向くか

向いているのは、作りたいものが自分の中にある人と、止まっていないかを自分で見に行ける人です。見に行かない人は、私のように88日気づきません。

向いていないのは、出てきたものを確かめずにそのまま使いたい人です。

結論：手を動かす所は任せられる。決める所は残る

手を動かす部分は、大きく肩代わりしてくれます。何を作るか、何を良しとするかの基準を決める役目は、最後まで自分に残ります。

このブログのためだけの固定費は、ドメイン代の年1,800円ほどです。Claude Code の契約は別に要りますが、ほかの作業と共用なので、ブログの費用には入れていません（運営費を全部公開する）。収益はまだ0円です。

実際に何をどう作ったかは 自動更新ブログを作った全記録 に、運用の実数は 運営記録 に公開しています。

このブログについて

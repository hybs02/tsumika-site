Claude CodeでKindle出版を半自動に。AIに渡した工程と、渡せなかった工程

執筆： hybs02

KDPKindle出版AIClaude Codeストック収入

「AIでKindle本を量産」と聞くと、ボタンひとつで売れる本が湧いて出るような印象を持つかもしれません。実際にKDPの制作を Claude Code に渡してみた結論を先に言うと、それは無理でした。作業量は減らせました。ただ、減ったのは下書きまでです。大事なのは「どこをAIに渡し、どこを人間が握るか」の線引きでした。

なぜ「全自動」が成り立たないのか

AIに丸投げして出てきた原稿は、読めるけれど中身が薄い。そのまま出した本は埋もれる、と私は見ています。

だから、企画の良し悪しと品質チェックだけは、人間が握ることにしました。そこを握ったうえで、下書きと整形までを渡す。これが「半自動」の中身です。

工程の分担（実際にこう分けた）

担当工程
人間市場調査と、どの隙間を狙うかの判断
人間差別化の方針（既存本に無い切り口を1つ決める）
人間最終的な品質チェックと推敲
AI決めた方針に沿ったアウトライン作成
AI各章の下書き執筆
AI整形やEPUB化のための機械的な処理

AIに渡す前に、「誰の、どんな悩みを、どう解決する本か」を人間が一文で決めておきます。ここが曖昧なまま投げると、それっぽいだけの中身のない原稿が返ってきます。

つまずきやすいところ

一気に全部出させない

「本を1冊書いて」と一発で頼むより、章ごとに方向性を確認しながら進めたほうが、品質が安定しました。ズレたまま最後まで書かれると、直す手間のほうが大きくなります。

生成物を信じすぎない

事実関係や具体例は、人間が確かめる前提で。スラスラ出てくるぶん、検証を飛ばしたくなります。ブログの下書きでも同じことが起きていて、経緯を知らないAIに読ませたら間違いが次々に出た話 に書きました。

守らないと本が消える、KDP側の決まり

AIで本を作るなら、Amazon側の決まりを把握しておく必要があります。ここからは、2026年11月に KDPのコンテンツガイドライン で確かめた内容です。

決まり中身
AI生成の申告新しい本を出す時と、既存の本を編集して出し直す時に、AI生成のテキスト・画像・翻訳があれば知らせる必要がある。表紙の画像も含む
AI生成に当たる範囲AIのツールで作った内容は、あとから大幅に編集しても「AI生成」と見なされる
申告が要らない範囲自分で書いたものをAIで直す・磨く・誤りを探す、案出しにだけ使う、は「AIアシスト」で開示不要
品質読者の満足を得られないコンテンツ、内容を正確に表していない記述は認められない
従わなかった時ガイドラインに従っていないコンテンツは、却下または削除される

下書きをAIに書かせる作り方は、あとでどれだけ手を入れても「AI生成」です。申告は義務なので、迷ったら申告する側に倒しています。

もう1つ、新規タイトルの数には上限があります。AIによる大量投稿への対策として2023年9月に導入が報じられたもので、数は上のガイドラインのページには書かれていません。量産のペースは、その枠の中で組むことになります。

決まりは変わることがあります。上の表は2026年11月の時点のものです。

実際にやってみて感じたこと

工程を分けてAIに渡す形にしてから、1冊にかかる時間は短くなりました。短くなったのは、アウトラインから下書きを起こす部分です。

一方で、時間が減らなかった工程もあります。企画と最終チェックです。むしろ、生成が速くなった分だけ、チェックすべき分量が増えて負担が上がった面もありました。

「AIを入れれば全工程が楽になる」わけではなく、楽になる工程と、変わらない工程がはっきり分かれました。

2冊目からは、同じ手順を流用しています。シリーズにして関連する本を並べる形にしていますが、それで売れるかは、まだ言えません。

向いているジャンル、向いていないジャンル

向いていると感じたのは、手順や知識を整理して伝えるタイプです。何かのやり方、入門的な解説、体系立てて説明できるもの。構成が組みやすく、AIの下書きも使いやすい。

向いていないと見ているのは、書き手固有の体験や人格が価値になるものです。エッセイ、体験記、独自の主張。「誰が書いたか」が中身そのものなので、AIに任せる部分がほとんど残りません。

効率よく作れるジャンルは、同じことを考える人も多いはずです。調べて数えたわけではありませんが、量産で埋もれるかどうかは、ここをどう考えるかで分かれると思っています。

短くなったのは下書きまで

私の場合、AIに渡して短くなったのは下書きと整形までで、企画と最終チェックの時間は減っていません。握るのは「企画」と「品質」です。

ほかに試した稼ぎ方と、やらなかったものは AIで副業を自動化する現実的な方法 に書きました。

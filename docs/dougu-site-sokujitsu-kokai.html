AI自動化で稼ぐラボ

Claude CodeでブログとAI自動化を実際に運用している記録

2026-11-12

ツールサイトを作ったその日に公開した。候補10個から選んだ理由と収益化の決め方

執筆： hybs02

実体験副業ストック収入収益化Claude Code

11月1日、喪中はがきの文面を作って、家のプリンタで縦書きに刷る無料の道具を公開しました。候補を出すところから公開まで、Claude Code と1日でやっています。

収益は0円です。この記事を書いている11月4日の時点で公開から3日で、検索から何人来たかもまだ分かりません。

デジタル商品の道具を作って出品0個だった話 では、作る所は速くなったのに、出す所で止まっていました。今回は、公開までを最初から作業の中に入れました。

条件と形

自分に出した条件は4つです。

条件中身
時間ほとんど使えない
元手0円から始める
営業しない
客とのやりとりしない

この条件で残ったのが、「検索で人が来る場所に、ブラウザの中だけで動く道具を置く」形です。入れてもらうものも、問い合わせの窓口もありません。処理は全部、使う人のブラウザの中で行い、入力はどこにも送りません。サーバを持たないので、置き場は GitHub Pages（無料）で足ります。独自ドメインも取っていません。

AIで副業を自動化する現実的な方法 では、道具の配布を「使われ続ける設計が重い」として見送っていました。サポートや環境の違いが重いなら、それが起きない形に絞ればいい、というのが今回の考え方です。

候補10個の比べ方

候補は、Claude Code の中で調べ物を受け持つ AI（サブエージェント）を2つ別々に動かして集め、拡張機能の売り場の数字は Claude Code がストアの画面でも確かめています。比べた項目はこうです。

項目見た所
需要の手がかりサイトなら推定の月間検索数（aramakijake.jp の Google の推定値）、拡張機能なら既存品の利用者数
競合の弱さ検索の上位が文例の記事ばかりで道具が無い、定番の評価が低い、など
手間と手入れ作る手間と、公開した後に直し続ける量
収入の形広告か、紹介料か、一部有料か

上位に来たものを抜き出すと、次のとおりです（数字は11月1日の時点）。

候補需要の手がかり競合の弱さ
喪中はがきの文面作成と印刷「喪中はがき 文例」推定26,480回/月続柄や月を入れて文面を作る道具が見つからない
香典袋・祝儀袋の書き方と印刷「香典袋 書き方」推定32,400回/月袋に直接刷る道具が見つからない

Chrome 拡張の候補（JSON を見やすく整えるもの）も上位に入っていて、こちらは2本目（世界向けとしては1本目）として準備しています。

外したものもあります。手入れが続くもの（相手のサイトの作りが変わるたびに直しが要る拡張など）と、量産のツールサイトや大手で埋まっているものです。

1本目に喪中はがきを選んだ理由

検索の数だけなら香典袋のほうが多い。それでも喪中はがきを先にしたのは、出す時期です。喪中はがきは年賀状より前、12月の初めまでに出すもので、11月中に公開しないと、今年の山に間に合いません。

もう1つは、部品の使い回しです。縦書きで紙に刷る部品（漢数字、和暦、字の大きさ合わせ、印刷）を作っておけば、香典袋にもそのまま使えます。

作ったもの

項目中身
入れるもの続柄・お名前・亡くなった年と月・年齢
出るもの決まりに沿った縦書きの文面。寒中見舞いにも切り替えられる
印刷家のプリンタで、はがきにそのまま刷る
保存入力は使う人のブラウザの中だけに残る

文面の組み立ては、検査を19件つけています。漢数字と和暦、「本年」と「昨年」の切り替え、2人分の文面、句読点を使わない決まりなどです。手元で回すと19件とも通ります。印刷の見本は、画面の無い Chrome で PDF に刷って、字がはがきからはみ出していないかを確かめています。

公開した日にやったこと

公開したあと、Google の Search Console にサイトを登録し、ページの一覧（sitemap）を送りました。送った直後の表示は「取得できませんでした」で、道具のページはインデックス登録のリクエストを出しています。

稼ぎ方は、広告ではなく紹介料にしました。広告は審査と、収益が出るまでの待ちが長いからです。文面を作った人が印刷も頼みたくなった時に、印刷の会社を紹介する枠を用意しました。リンクには必ず「PR」と付けます。

ただ、紹介する会社はまだ0件で、0件の間は枠が出ない作りです。紹介料の仕組みへの登録には本人確認と口座が要ります。そこは私の番で、まだやっていません。

サイトの名前と場所は、ここでは出しません。このブログから見に行く人が混ざると、検索から人が来たのかが分からなくなるためです。

2週間後の決め方

判定は11月15日ごろ、Search Console の表示回数とクリック数で見ます。次の手は、公開する前に決めておきました。

2週間後の状態次の手
検索の索引にまだ入っていない待つ（Search Console の URL 検査で確かめる）
索引に入っているのに表示されない題名と検索語を変えて、1回だけやり直す
見られているのに使われない捨てる
使われているのにお金にならない紹介の置き方を変えて、1回だけ試す
お金になった力をこれに集める

先に決めておくのは、数字を見てから理由を探すと、捨てる判断ができなくなるからです。

ただ、この表にはまだ穴があります。道具は入力をどこにも送らず、アクセス解析も入れていないので、「使われたか」を数える仕組みがありません。紹介の会社も0件なので、お金になることも今は起きません。11月15日の判定で使えるのは、上の2行までです。下の3行は、数える仕組みと紹介料の登録ができてからです。

残っているのは、決めること

残っているのは紹介料の登録で、作業というより、私がいつやるかを決めることです。

結果は、判定のあとにこのブログに書きます。見られていなかった時も書きます。

このブログについて

当サイトは「AIで自動更新するブログ」を実際に運営しながら、その記録を公開しています。仕組みの全工程は構築の全記録に、アクセスや収益の実数は運営記録にまとめています。

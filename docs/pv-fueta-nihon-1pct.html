Claude CodeでブログとAI自動化を実際に運用している記録

2026-11-05

記事ゼロでPVが増えた。Cloudflareで中身を見たらボットだった

執筆： hybs02

実体験ブログ運営アクセス解析収益化Cloudflare

このブログは8月3日を最後に、新しい記事を出していませんでした（止まっていた事情は 88日止まっていた話 に書きました）。それでも、Cloudflare で数えているアクセス数（PV）は減りませんでした。記事を4本出した7月が1,913、1本も出していない9月が2,287、10月が2,288です。

国別に分けると、9月と10月は日本からのアクセスが1%未満でした（リクエスト単位）。日本語で書いているブログなので、PVの大半はボットだと見ています。

収益は0円、メールの購読者は1人です。

記事の数とPVが逆に動いた

数字は Cloudflare の解析から、11月1日に月ごとに取り直したものです。

月公開した記事PVリクエスト日本からの割合国・地域の数

6月はサイトを始めた月です。止まる直前の7月と比べると、PVは2割ほど増えました。リクエスト（画像やスタイルの読み込み、存在しないページへの要求も含めた、サイトへの要求の総数）は、6月から9月で2.8倍です。何が増えたのかまでは分けていません。アクセス元の国と地域は41から73に広がりました。

日本からの割合は、PVではなくリクエストで出しています。今回の問い合わせでは、国別はリクエスト数しか返ってこなかったためです。9月の日本からのリクエストは、22,446のうち32でした。

管理用のパネルと運営記録では、7月のPVを1,407と記録していました。7月26日に月の途中で取った値が、そのまま月の値として残っていたものです。パネルが記録済みの月も毎回取り直すように Claude Code に直してもらい、今は1,913になっています。

ボットをどう見分けたか

Cloudflare は、アクセス元が名乗るブラウザの種類も数えています。10月のPVでは、検索エンジンの巡回（GoogleBot・BingBot・AppleBot）と名乗るものが76、Cloudflare がブラウザを判別できなかったものが583、コマンドから直接取りに来たもの（Curl）が14ありました。残りは Chrome や Safari を名乗っていますが、名乗りだけなら機械でも同じにできます。

国別の数字と合わせて、人が読んだPVはごく一部だと見ています。何割かは分かりません。

この数え方を選んだのは自分です。アクセス解析がずっと0だった話 で書いたとおり、最初に入れた解析は、ページに埋め込んだプログラムがブラウザから報告する方式で、広告ブロックに止められて0のままでした。そこで、サイトに届く手前の通り道で数える方式に切り替えました。こちらは取りこぼしませんが、人もボットも全部数えます。あの記事で取りこぼさないほうを選んだのは、取りこぼしが無いという意味では合っていました。人の数という意味では外れていました。

自分のサイトで確かめる手順

Cloudflare を通しているサイトなら、同じことを確かめられます。

  1. Cloudflare の画面で、サイトの Analytics → Traffic を開き、国別の地図と上位の国を見る。無料プランでは国別はリクエスト単位です。
  2. 月ごと・ブラウザ別まで見たいなら、Cloudflare の GraphQL API に問い合わせる。使ったのは httpRequests1dGroups で、取った項目は次のとおりです。API トークンにはゾーンの解析を読む権限が要ります。

sum { pageViews requests
      browserMap { pageViews uaBrowserFamily }
      countryMap { clientCountryName requests } }
  1. 日本語のサイトなのに日本の割合が数%しかなければ、PVを読者の数として扱わない。

2つ目は、自分では書いていません。管理用のパネルが月のPVと訪問者数の合計を取ってくる仕組みは前から Claude Code に作ってもらっていたので、「同じ鍵で、月ごとに国とブラウザの内訳も取れないか」と頼みました。パネルと同じ問い合わせに国とブラウザの項目を足したものを書いて、6月から10月の分を取ってくれました。合計のPVが、パネルに記録してある6月と8月から10月の値と同じことも確かめています。

稼ぐ判断にPVは使えない

月2,300のPVを見ると、広告を貼れば少しは入るのではと考えたくなります。でも大半がボットなら、広告を見る人もいません。収益化の判断にこのPVを使うと、いない読者を当てにすることになります。

いま手元にある、稼ぐことに関わる数字はこれだけです。

収益化を急がなかった話 では、見直しの合図を「検索から継続的に人が来ているか」に置き、半年経っても訪問がほぼゼロなら書くものを見直す、と書きました。6月に始めたので、半年は12月です。その時に使う数字はPVではなく、検索結果に何回出て何回押されたか（Google の Search Console の表示回数とクリック数）です。こちらはまだ毎月の記録に入れておらず、この記事でも出していません。

気づくべきだったこと

11月に取り直すまで、月ごとのPVを見比べたことはありませんでした。記事を足さなくても、検索に載っていけばPVが伸びることはあります。だから増えたこと自体はおかしくありません。おかしかったのは中身で、日本語のブログに日本から32リクエストしか来ない月がありました。それに気づけたのは、内訳を分けてからでした。

パネルには、まだ日本からの割合も、検索の表示回数も出していません。費用の内訳は 運営費を全部公開した記事 にまとめています。
